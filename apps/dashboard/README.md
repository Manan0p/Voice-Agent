# Personal AI Caller — Web Dashboard

The Next.js 14+ (App Router, Tailwind CSS, shadcn/ui) user dashboard will be built in **Phase 15** after the underlying call data models and APIs are established.

## Planned Capabilities
- Realtime call monitor and human handoff controls ("Take Call", "Keep AI", "End Call")
- Complete call history, transcripts, audio recordings, and summaries
- Contact management & trust level configuration
- Knowledge base management for RAG
- Agent configuration and notification routing
