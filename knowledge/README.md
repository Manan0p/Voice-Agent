# Knowledge Base (Phase 9 RAG)

Store reference markdown files used for context retrieval during calls.

## Structure
- `personal_info.md`: Safe owner details (name, schedule preferences, safe disclosures)
- `frequently_called_contacts.md`: Notes on family, close friends, key contacts
- `preferences.md`: Call screening rules, availability hours, meeting preferences
- `faq.md`: Answers to common queries (work, appointments, delivery handling)
